# Как получить APK без компьютера

1. Создайте аккаунт GitHub и новый публичный или приватный репозиторий.
2. Загрузите содержимое этой папки в репозиторий (папка `.github/workflows` тоже должна быть загружена).
3. Откройте вкладку **Actions**.
4. Выберите **Build Auto Profit APK**.
5. Нажмите **Run workflow**.
6. После завершения откройте выполненный workflow.
7. Внизу в разделе **Artifacts** скачайте `auto-profit-apk`.
8. Внутри будет `app-release.apk`.

Workflow автоматически создаёт Android-часть Flutter-проекта, устанавливает зависимости, запускает анализ и собирает release APK.
