# Auto Profit 1.0

Офлайн-приложение для учёта автомобилей, расходов и прибыли.

## Уже реализовано
- карточка автомобиля: марка, модель, год, VIN, госномер, пробег, продавец, даты, заметки;
- статусы: Куплен / В ремонте / Готов к продаже / На продаже / Продан;
- цена покупки и продажи;
- неограниченное количество расходов;
- собственные категории расходов;
- автоматические итоги расходов, вложений и прибыли;
- фото с камеры и галереи;
- PDF и другие документы;
- локальное хранение без интернета;
- поиск по VIN, госномеру, марке и модели;
- общий экран со статистикой.

## Сборка
1. Установить Flutter 3.24+.
2. Распаковать проект.
3. Выполнить `flutter pub get`.
4. Для Android: `flutter build apk --release`.
5. Для iPhone: `flutter build ipa --release` на Mac с Xcode.

После `flutter create .` Flutter создаст стандартные папки android/ и ios/, если они отсутствуют.
